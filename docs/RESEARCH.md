## Refresh the configuration snapshot

Run from the repository root with Python 3; no training dependencies are imported:

```bash
python scripts/sync-research.py
python scripts/sync-research.py --check
npm test
npm run typecheck
npm run build
```

The script reads notebook code without executing it, computes notebook and ONNX hashes, and derives input windows, horizons, split boundaries and features. A reviewed notebook hash prevents changed code or new outputs from silently republishing stale descriptive labels. Review those changes before updating `REVIEWED_NOTEBOOK_SHA256`; the horizon guard also requires review when the evaluation design changes. The source link is pinned to the last commit that changed the notebook. No personal files, API keys, dataset downloads or Colab Drive mounts are needed for this operation.
